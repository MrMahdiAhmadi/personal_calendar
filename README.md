### Overview
A clean, focused weekly planner built around rhythmic time blocking. It helps you organize your 24-hour routine through alternating work sprints and recovery breaks, with customizable intervals, integrated focus timers, and cross-device sync.

### Key Features
- **⚙️ Customizable Block Intervals:** Personalize work (10–180 min) and break (5–60 min) lengths with automatic 24-hour cycle regeneration (defaults to 90m work / 30m break ultradian rhythm).
- **⏱️ Persistent Floating Pomodoro & Calendar Break Sync:** Run focus sessions directly inside any time block with a persistent floating timer bar across the planner, live countdown in tab title, Web Notifications, and automatic transition into the schedule's next calendar break block.
- **📱 Mobile Bottom Navigation & Ergonomic UX:** One-handed mobile experience with quick thumb-reach navigation (Today, Week Matrix, Tasks Bank, Time Insights) and a decluttered top header.
- **📊 Time Insights & Analytics:** Visual feedback dashboard breaking down deep work hours, category time distribution charts, and schedule adherence commitment rates for the current week and past 30 days.
- **📱 PWA & Offline-First:** Fully functional without internet access, installable as a native-like app on desktop and mobile with instant local persistence.
- **🔄 Flexible Matrix & Daily Views:** Switch seamlessly between a high-density 7-day matrix view and focused daily views.
- **🛠️ Consolidated Unified Settings:** Organized modal tab system for preferences, Supabase cloud sync, JSON backups, and custom category tags.
- **📋 Category Task Bank & Sub-tasks:** Organize backlog tasks by color-coded domains and link them directly as checklists within time blocks.
- **☁️ Cloud Sync via Supabase:** Optional real-time synchronization across your devices using your own free Supabase database.
- **🌐 Bilingual & Themed:** Full English (LTR) and Persian (RTL) support with dark and light themes.

### Quick Start
Open `index.html` in any browser, or run locally:

```bash
npx serve .
```

### معرفی
برنامه‌ای ساده و متمرکز برای مدیریت و زمان‌بندی هفتگی ۲۴ ساعته بر پایه چرخه‌های متناوب کار و استراحت؛ همراه با تایمر تمرکز، امکان شخصی‌سازی بازه‌های زمانی و همگام‌سازی ابری بین دستگاه‌ها.

### قابلیت‌های اصلی
- **⚙️ شخصی‌سازی بازه‌های کار و استراحت:** امکان تغییر دلخواه مدت زمان کار (۱۰ تا ۱۸۰ دقیقه) و استراحت (۵ تا ۶۰ دقیقه) با محاسبه خودکار چرخه‌ها (به‌صورت پیش‌فرض ریتم اولترادیان ۹۰/۳۰).
- **⏱️ تایمر شناور پومودورو و هماهنگی با بلوک استراحت تقویم:** اجرای سشن‌های تمرکز با نوار شناور و پیوسته در تمام صفحات، نمایش زنده در عنوان تب مرورگر، نوتیفیکیشن دسکتاپ و ورود خودکار به بلوک استراحت بعدی تقویم در پایان چرخه‌ها.
- **📱 ناوبری ارگونومیک پایین صفحه برای موبایل:** دسترسی سریع و آسان با انگشت شست به ۴ بخش کلیدی (نمای امروز، جدول هفته، بانک تسک‌ها، گزارش و تحلیل) همراه با هدر خلوت و بدون بار شناختی.
- **📊 گزارش و تحلیل زمان (Time Insights):** داشبورد تحلیلی و انگیزشی برای نمایش ساعت‌های کار عمیق، نمودار توزیع حوزه‌ها و تگ‌ها، و نرخ تعهد به چرخه‌ها در طول هفته و ماه اخیر.
- **📱 اپلیکیشن تحت‌وب (PWA) و کارکرد آفلاین:** قابلیت نصب روی موبایل و دسکتاپ و ذخیره آنی داده‌ها در حافظه مرورگر بدون نیاز به اینترنت.
- **🔄 نماهای متنوع ماتریسی و روزانه:** جابه‌جایی سریع بین نمای کلی جدول ۷ روز هفته و نماهای متمرکز روزانه.
- **🛠️ پنل تنظیمات یکپارچه و تب‌بندی‌شده:** تجمیع تمام تنظیمات عمومی، اتصال به دیتابیس ابری Supabase، پشتیبان‌گیری فایل‌ها و مدیریت برچسب‌ها در یک بخش واحد.
- **📋 بانک تسک‌های حوزه‌ها و چک‌لیست:** دسته‌بندی تسک‌ها در حوزه‌های رنگی مختلف و انتساب آسان آن‌ها به بلاک‌های زمانی.
- **☁️ همگام‌سازی ابری اختیاری با Supabase:** امکان اتصال امن و همگام‌سازی لحظه‌ای داده‌ها بین لپ‌تاپ و گوشی.
- **🌐 دو زبانه و دارای تم:** پشتیبانی کامل از زبان‌های فارسی (راست‌چین) و انگلیسی (چپ‌چین) همراه با حالت‌های دارک و لایت.
